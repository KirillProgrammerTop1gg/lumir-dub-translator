# Lumir Dub Translator

Локальное приложение для английской расшифровки видео с разметкой говорящих. Реплики можно просматривать рядом с видео, исправлять и назначать говорящим имена. Дополнительный AI-этап объединяет соседние фрагменты в предложения и делает контекстный перевод. Проекты сохраняются локально; доступны переименование, удаление и экспорт SRT, TXT или JSON.

## Подготовка

Установите Python 3, [uv](https://docs.astral.sh/uv/getting-started/installation/), [Node.js с npm](https://nodejs.org/en/download) и [FFmpeg](https://ffmpeg.org/download.html) (`ffmpeg` и `ffprobe` должны быть в `PATH`). Затем запустите из папки проекта:

```bash
./start.sh
```

В Windows запустите `start.bat` (или `py -3 start.py`). Скрипт сам подготовит Python 3.13 и зависимости, запустит оба сервера и откроет http://127.0.0.1:5173/projects. При первом запуске установка моделей может занять время. Для остановки нажмите `Ctrl+C`. Если браузер открывать не нужно, используйте `python3 start.py --no-browser`.

Для модели определения говорящих войдите в Hugging Face, примите условия на странице [pyannote Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1) и создайте токен того же аккаунта с правом чтения модели. Запишите его в корневой `.env`: `HF_TOKEN=ваш_токен`, либо откройте вкладку «Настройки .env» в приложении. Ошибка 403 означает, что этому аккаунту ещё не предоставлен доступ к модели; после принятия условий запустите обработку повторно. Для AI-перевода по умолчанию используется локальная Ollama; OpenAI API не требуется.

Если нужны отдельные терминалы или режим разработки, команды остаются такими:

```bash
uv sync --python 3.13 --extra ml
uv run --extra ml lumir-api
```

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте http://127.0.0.1:5173/projects. На странице «Проекты» можно переименовать проект. Вкладка «Обработка» показывает активные задачи, их прогресс и позволяет запустить или повторить обработку любого доступного проекта. Задачи выполняются по очереди, поэтому можно отправить несколько видео подряд. Отдельная вкладка «Настройки .env» позволяет сохранить или удалить токены и выбрать модели Ollama и OpenRouter; сайт показывает наличие ключей, но не их значения. У каждого проекта есть отдельные страницы транскрипта, говорящих, AI-перевода и настроек с экспортом; прямые ссылки на них работают после обновления браузера. Для NVIDIA GPU нужны совместимые драйверы CUDA и сборка PyTorch; CPU работает без GPU. Первый запуск скачивает веса моделей. Видео, расшифровки и правки сохраняются в `data/` (путь можно задать через `LUMIR_DATA_DIR`).

## Проверки

```bash
uv sync --python 3.13 --extra test
uv run --extra test pytest
cd frontend && npm run build && npm run check:routes && npm run test:ui
```

Поддерживаются MP4, MKV, MOV и WebM до 30 минут и 2 ГБ. Во время обработки страница показывает этап и прогресс; при первой загрузке весов моделей процент может временно не меняться. Если перезапустить сервер во время обработки, прерванные задачи получат статус ошибки и их можно будет запустить снова. Приложение рассчитано на одного локального пользователя. Точечные замены терминов запланированы следующим этапом.

После транскрипции откройте вкладку «AI-перевод», выберите локальную Ollama или OpenRouter, укажите язык и контекст сцены и нажмите «Анализировать и перевести». Страница проверяет наличие локальной модели и ключа OpenRouter; если Ollama недоступна, а ключ OpenRouter настроен, для нового перевода выбирается OpenRouter. Для локального варианта установите Ollama, загрузите модель командой `ollama pull qwen2.5:7b` и запустите сервер Ollama. Название модели можно поменять во вкладке «Настройки .env» через `OLLAMA_MODEL`. Для OpenRouter укажите `OPENROUTER_API_KEY` и при необходимости `OPENROUTER_MODEL`. Видео не отправляется провайдеру; OpenRouter получает текст транскрипции и контекст. Перевод хранится отдельно от исходных реплик, его можно исправлять вручную и выгрузить как субтитры или как диалог вида «Имя — реплика» без таймкодов. Повторный AI-анализ заменяет предыдущий перевод и его правки. В длинном видео анализ выполняется несколькими запросами по небольшим группам реплик.

Английский диалог в формате «Имя — реплика» можно скачать как из проекта до перевода, так и со страницы перевода. Соседние фрагменты с одинаковым отображаемым именем объединяются в одну строку до смены имени. Английский файл собирается из актуального транскрипта в браузере. Если модель присвоила нескольким персонажам один ID, отметьте их реплики в транскрипте и используйте «Назначить говорящего»; нового персонажа можно добавить во вкладке «Говорящие».

На экране перевода видео расположено над английской и русской колонками. При наведении на английское слово подсвечивается соответствующий русский фрагмент, если модель вернула связь и этот фрагмент ещё есть в тексте; иначе подсвечивается вся русская реплика. Для показа до трёх переводов из Cambridge Dictionary укажите отдельный `CAMBRIDGE_API_KEY` во вкладке «Настройки .env». Код словаря по умолчанию `english-russian`; его можно изменить там же. Без ключа остаётся ссылка на статью Cambridge, а перевод «В этой реплике» обозначает связь, созданную AI, не словарные данные. Доступ к [Cambridge Dictionary API](https://dictionary.cambridge.org/develop.html) оформляется отдельно.

На странице «Транскрипт» можно отфильтровать реплики по говорящему, исправить текст и выбрать говорящего у каждой реплики. Чтобы объединить несколько реплик, отметьте соседние строки флажками, выберите говорящего для результата и нажмите «Объединить выбранные». Для разделения поставьте курсор между словами, нажмите «Разделить», выберите говорящего для второй части и подтвердите. При наличии времени отдельных слов граница берётся между ними; иначе она рассчитывается по доле слов в тексте. После изменения реплик старый AI-перевод помечается как устаревший, пока вы не запустите его снова.

NVIDIA GPU ускоряет обработку, но не меняет качество распознавания говорящих. Если персонажи определились как один, откройте вкладку «Говорящие», укажите точное число голосов во всём видео и запустите повторную обработку. Она заменит текущую расшифровку и ручные правки. Если автоопределение нашло только один голос, приложение автоматически повторит разметку с двумя голосами; для видео с одним человеком явно выберите 1. Для точечной коррекции отметьте реплики в транскрипте, выберите существующего говорящего и нажмите «Назначить говорящего». Во вкладке «Говорящие» можно добавить или удалить персонажа: реплики удалённого персонажа и перевод сохранятся с пометкой «Неизвестно». Автоматическое определение говорящих может ошибаться при музыке, коротких репликах или одновременной речи.
